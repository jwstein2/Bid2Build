## 4. Implications for Built2Bid [researcher inference]
- Sage 100 Contractor is the **depth benchmark**: cost code × cost type, commitments, subcontract COs, AR/AP retention, SOV pay apps, WIP, compliance warnings, lien waivers. QBO Advanced is now the **SMB cloud benchmark** for basic construction billing.
- Built2Bid's V3 target, "QB bookkeeping + Sage job-cost depth + Built2Bid upstream", is not served by any single SMB product today. The hard parts to do *better* than Sage are cloud, mobile, ease of setup (trade presets), and starting from the signed proposal. **Do not try to match Sage on payroll or union/certified reporting** (excluded by the addendum).
- Copy Sage's **warning-not-blocking** pattern for compliance and overbilling. It matches the addendum's "no claims of verification; no auto pay".
