# 02 Platform-Specific Audience Profiles

Built2Bid Growth OS · Phase 2 · model v2.0.0 (2026-11-23) · generated by scripts/render_reports.py, do not edit by hand.

The six audience layers are kept separate on purpose. Moving down the list, each layer is narrower and less certain. Only the first layer has probability-survey evidence; the construction layer has no source at all [G201]; the reachable-audience layer needs logged-in ad tools [G202]; the last two are model outputs [M].

Pew figures describe U.S. adults [P1:S11]. Jobber figures describe 1,050 surveyed home-service owners and how they get *their own* customers, not how they buy software [P1:S08]. Neither is a contractor-software statistic.
