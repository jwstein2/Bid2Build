# Bid2Build

Estimates and proposals for every trade. "What Are You Bidding Today?"

- Pick a trade, build an estimate with markup **or** margin, choose what the customer sees per section, and export a branded US Letter PDF.
- Free: 3 finalized exports per calendar month (UTC). Unlimited: $19.99/month or $149/year via Stripe.

Docs: [Setup](docs/SETUP.md) · [Architecture](docs/ARCHITECTURE.md) · [Security](docs/SECURITY.md)

```bash
npm install && cp .env.example .env.local && npm run dev
npm test && npm run test:db && npm run build
```
